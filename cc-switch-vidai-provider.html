1. 新建 Codex Provider

打开 CC Switch，左侧选择 Codex，点击右上角添加供应商，选择自定义配置。不同版本按钮文字可能略有差异。

显示名称VidAI 胃袋API Base URLhttps://api.david-ai.net/v1 上游格式OpenAI Responses API API Key从你自己的 VidAI 控制台复制 模型 ID从当前控制台复制，不要使用过期教程里的固定模型名

2. 如果需要检查 TOML

CC Switch 会管理连接字段。手动核对时，关键结构应类似下面这样；把占位符替换为控制台当前模型，但不要把真实 Key 写进公开文件。

model_provider = "custom"
model = "控制台当前模型ID"
model_reasoning_effort = "high"
disable_response_storage = true

[model_providers.custom]
name = "VidAI 胃袋API"
base_url = "https://api.david-ai.net/v1"
wire_api = "responses"
requires_openai_auth = true

3. 切换后重启 Codex

Codex 通常只在启动时读取 Provider 和模型配置。切换供应商或模型后，彻底退出当前 Codex 会话并重新启动，再执行验证任务。

4. 不要只测一句对话

固定一个真实仓库任务，连续运行至少 3 次，记录：

  • 是否完成代码修改并通过测试；
  • 是否出现 SSE 断流、429、502 或自动重试；
  • 文件、Shell 和测试工具是否形成完整闭环；
  • 首字延迟、总任务耗时、Token 与实际扣费；
  • 失败后是否能在 CC Switch 请求日志或站内用量记录中定位。
