REPRODUCIBLE METHOD

怎样得到可信数字？

  1. 固定同一个仓库、模型、任务和验收标准，连续测试至少 3 次。
  2. 从服务控制台或可观测记录填写输入、缓存输入、输出、重试与最终扣费。
  3. 一次短问答不算成功；预定修改完成、测试通过，才计入任务成功率。
  4. 不同 Provider 必须使用接近的测试时间窗口，避免把容量波动当成价格优势。
每次成功任务成本 = 任务数 × 平均计费尝试次数 × 单次尝试成本 ÷（任务数 × 成功率）
