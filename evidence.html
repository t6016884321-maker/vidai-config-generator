VERIFIED PUBLIC FACTS

当前可公开验证的事实

官网与注册页已验证

官网与注册页可公开访问；注册表单包含可选 Promo Code 字段。

协议入口已验证

匿名请求 `/v1/models`、`/v1/responses`、`/v1/messages` 返回鉴权要求，说明路由存在；这不等于已验证某个具体模型或所有事件兼容。

用量查询入口已验证

官网公开导航提供 Usage lookup。用户仍应核对逐请求 Token、状态和实际扣费是否与自己的账单一致。

线路监控登录后可见

监控入口当前要求登录；它不是匿名公开状态页，不应被描述为无需登录的实时可用性证明。

免费验证工具已验证

8 项兼容性自测、真实成本计算器和15 分钟验收清单均公开且无需提交 API Key。

渠道归因基础能力

注册页存在 Promo Code 字段，现有注册链接支持 aff 与 UTM；具体用户优惠、佣金比例和结算周期必须单独确认，不能从字段存在推导。

NOT PUBLICLY ESTABLISHED

目前不能对外承诺的事项

匿名公开状态页

监控页要求登录，公开访客无法直接核对实时线路状态和历史可用性。

退款与故障补偿

公开条款正文目前没有足够内容证明具体退款、超时减免或故障补偿规则。

发票与企业合同

公开页面没有足够证据证明可开何种发票、合同主体和企业支持边界。

固定最低价与永久稳定

模型、上游、容量和价格会变化，不作绝对最低价或永久可用承诺。

具体模型真实性

路由存在不等于每个模型来源已验证。评测者应使用自己的任务、日志与输出质量做交叉检查。

自动化返佣政策

aff、UTM 和 Promo Code 可用于基础归因，但固定 CPA、充值分成和提现规则尚无公开承诺。
